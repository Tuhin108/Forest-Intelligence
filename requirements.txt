# --------------------------------------------------------------------------
# Deployment note (Hugging Face Spaces, free CPU-basic tier):
#
# A plain `pip install torch` resolves to a CUDA-enabled build and drags in
# several GB of NVIDIA libraries that a CPU-only Space never uses, which
# slows the build and can exhaust the free tier's disk/build-time budget.
# Install the CPU-only build explicitly instead, *before* installing this
# file, e.g. in your Space's Dockerfile or build step:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt
#
# On first run, DeepForest downloads its pretrained weights (~130 MB) from
# Hugging Face Hub (weecology/deepforest-tree) and caches them -- this
# requires the host to have outbound internet access to huggingface.co.
# --------------------------------------------------------------------------
